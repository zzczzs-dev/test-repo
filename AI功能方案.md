================================================================================
                        AI 智能推荐功能方案设计
================================================================================

项目名称：今天吃什么
功能模块：AI 智能推荐

================================================================================
                              功能概述
================================================================================

本方案为"今天吃什么"产品新增两个 AI 智能功能：
1. AI 菜品点评 - 根据用户忌口和用餐时间，AI 智能点评当前推荐的菜品
2. AI 菜品推荐 - 根据用户忌口和现有菜品库，AI 自动推荐新菜品并可一键入库

================================================================================
                              技术方案
================================================================================

【方案一：使用 DeepSeek API】（推荐）
------------------------------------------------------------------------------
优势：
- 国内访问速度快
- 价格实惠
- 中文理解能力强
- 无需翻墙

接入方式：
- 使用 DeepSeek-V3 或 DeepSeek-Chat 模型
- 通过官方 API 调用
- 免费额度：10万 Tokens（注册赠送）

API 文档：https://platform.deepseek.com/

--------------------------------------------------------------------------------

【方案二：使用 OpenAI API】
------------------------------------------------------------------------------
优势：
- 模型能力强
- 生态成熟

劣势：
- 需要翻墙
- 价格较高
- 国内访问不稳定

================================================================================
                              功能设计
================================================================================

【功能一：AI 菜品点评】
------------------------------------------------------------------------------
入口位置：推荐结果区域下方

功能描述：
- 用户点击"AI 点评"按钮
- AI 根据当前推荐的菜品、用户忌口、用餐时间生成点评
- 点评内容包括：菜品搭配建议、营养分析、口味点评

交互流程：
1. 用户选择分类并点击"随机推荐"
2. 推荐结果显示后，出现"AI 点评"按钮
3. 用户点击按钮，AI 开始分析
4. 分析完成后，显示点评结果
5. 用户可选择"换一道"重新点评

数据输入：
- 当前推荐的菜品列表
- 用户输入的忌口
- 当前用餐时间（早餐/午餐/晚餐）

--------------------------------------------------------------------------------

【功能二：AI 菜品推荐】
------------------------------------------------------------------------------
入口位置：菜品管理区域

功能描述：
- 用户点击"AI 推荐新菜品"按钮
- AI 根据用户忌口和现有菜品库，推荐新菜品
- 推荐的新菜品可一键添加到数据库

交互流程：
1. 用户在菜品管理区域
2. 点击"AI 推荐新菜品"按钮
3. AI 分析现有菜品库和忌口
4. 生成新菜品推荐列表
5. 用户可选择"添加到菜品库"

数据输入：
- 现有菜品库数据
- 用户忌口
- 分类偏好

================================================================================
                              数据流设计
================================================================================

【AI 菜品点评数据流】
------------------------------------------------------------------------------
用户点击点评
    ↓
获取当前推荐菜品列表
    ↓
获取用户忌口输入
    ↓
获取当前时间（判断用餐时间）
    ↓
构造 Prompt
    ↓
调用 DeepSeek API
    ↓
解析返回结果
    ↓
显示点评内容

--------------------------------------------------------------------------------

【AI 菜品推荐数据流】
------------------------------------------------------------------------------
用户点击推荐
    ↓
获取现有菜品库
    ↓
获取用户忌口
    ↓
构造 Prompt（含菜品库信息）
    ↓
调用 DeepSeek API
    ↓
解析返回结果（提取菜品名、分类、做法）
    ↓
显示推荐列表
    ↓
用户点击"添加到数据库"
    ↓
调用 Supabase API 插入数据

================================================================================
                              API Key 管理
================================================================================

方案设计：
- 用户首次使用时需输入 API Key
- API Key 保存在浏览器 localStorage
- 支持随时修改和清除

安全考虑：
- API Key 仅存储在用户本地浏览器
- 不上传到服务器
- 建议用户使用环境变量方式管理
