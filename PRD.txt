================================================================================
今天吃什么 - 一页纸 PRD
================================================================================

一、目标用户
--------------------------------------------------------------------------------
选择困难症用户：每天面对"吃什么"问题犹豫不决
上班族：时间紧张，希望快速做出餐饮决策
家庭用户：为全家做饭时需要多样化的菜品建议
饮食控制者：需要排除特定忌口食材的用户


二、核心痛点
--------------------------------------------------------------------------------
1. 选择困难：每天重复面对"吃什么"问题，犹豫不决，浪费时间
2. 忌口难记：想排除某些食材但每次都要重新输入，忘记之前的忌口选择
3. 菜品单一：经常只想到常吃的几道菜，缺乏灵感


三、核心功能
--------------------------------------------------------------------------------
1. 随机推荐引擎：根据用户选择的分类随机推荐菜品，支持多分类同时推荐
2. 忌口过滤系统：支持输入忌口关键词，推荐结果自动排除
3. 数据持久化：菜品数据存储在浏览器localStorage，支持自定义分类和菜品管理
4. 推荐历史：保存推荐历史记录，最多20条


四、数据模型
--------------------------------------------------------------------------------
菜品数据（localStorage存储）：
{
  "dishesData": {
    "主食": ["米饭", "面条", "馒头", "粥", "饺子", "包子"],
    "荤菜": ["宫保鸡丁", "红烧肉", "水煮鱼"],
    "素菜": ["麻婆豆腐", "蒜蓉西兰花"],
    "小吃": ["寿司", "披萨", "汉堡"]
  }
}

历史记录数据（localStorage存储）：
{
  "recommendHistory": [
    { "date": "3-9 14:30", "dishes": "主食:炒饭 荤菜:红烧肉" }
  ]
}


五、成功标准
--------------------------------------------------------------------------------
页面加载时间：小于2秒
推荐响应时间：小于100毫秒
动画流畅度：60fps
移动端适配：正常显示，无布局错乱
